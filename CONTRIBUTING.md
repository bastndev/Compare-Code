# Contributing to Compare Code

Compare Code is deprecated. Its functionality now lives in [ATM](https://marketplace.visualstudio.com/items?itemName=bastndev.atm), so new feature work should be directed there.

This repository only contains the migration shim. For a local check:

```bash
npm install
npm run compile
```

Please keep changes limited to the migration flow, metadata, and documentation. Bug reports can be opened in the [Compare Code issue tracker](https://github.com/bastndev/Compare-Code/issues).
