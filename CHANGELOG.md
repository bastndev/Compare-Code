# Compare Code Changelog

A VS Code extension for comparing code files visually and efficiently.

## Features

- **Visual Comparison**: Intuitive interface for side-by-side file comparison
- **Complete Integration**: Works seamlessly with VS Code, Cursor, Windsurf, Trae.ai, and Kiro
- **Easy Access**: Quick command and keyboard shortcut for instant access
- **Clean Interface**: Optimized view for code difference analysis

  Discover more extensions [here](https://gohit.xyz/)
